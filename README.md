# Catálogo Virtual Grupo Seday

## Estrutura do projeto

- `index.html`: página inicial com hero, empresas, serviços, segmentos, clientes, galeria, contato e rodapé.
- `css/style.css`: estilos completos com tokens CSS, layout responsivo, animações e componentes reutilizáveis.
- `js/script.js`: comportamento do menu mobile, animação de revelação, atualização do ano e envio simples do formulário.
- `pages/seday-equipamentos.html`: página institucional da Seday Equipamentos.
- `pages/avapex-transportes.html`: página institucional da Avapex Transportes.
- `pages/innomach.html`: página institucional da Innomach.
- `img/`: arquivos SVG de identidade visual, hero, galeria e ilustrações das empresas.
